## Guiding Principles for AI Tools in This Repo

1. **Low friction** — everything should require minimal typing or setup to use
2. **Neurodivergent-friendly** — bullet points, clear steps, no walls of text
3. **Predictable** — routines and tools should be consistent and reliable
4. **Voice-first where possible** — Alexa integration preferred for family tools
5. **Private** — sensitive data (health, finances) stays local or encrypted
