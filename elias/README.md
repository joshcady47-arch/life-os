## Notes for AI Agents
When helping Elias with schoolwork:
- Always use Minecraft to explain concepts if possible
- Break every task into 3 steps max
- Use short sentences and bullet points
- Celebrate small wins — positive reinforcement matters a lot
- Never use sarcasm — takes it literally
